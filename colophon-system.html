05 / Principles

Motion

Motion is quiet and earns its place. One easing curve everywhere, entrance over decoration, and never at the cost of legibility or reduced-motion users.

One curve

cubic-bezier(.22, 1, .36, 1) on nearly everything, so the whole site feels like one hand.

Reveal, don't perform

Content settles in on scroll; nothing loops or demands attention while you read.

Base state is visible

Animations start from the end state, so a stalled clock or print never strands content invisible.

Respect the user

prefers-reduced-motion collapses every animation to a clean, instant state.
